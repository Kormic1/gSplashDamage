# gSplashDamage

gSplashDamage is a Union plugin for Gothic 1, Gothic Sequel, Gothic 2 and Gothic NotR.

This plugin implements splash damage in Gothic, meaning you can hit multiple targets with one swing simultaneously.

Here you can watch a demonstration of the plugin being a part of a guide for implementing plugins in Union Framework (click the image below):

[![Demonstration](http://img.youtube.com/vi/YN-xTsrEpHg/0.jpg)](https://www.youtube.com/watch?v=YN-xTsrEpHg "Union Framework Tutorial - Learn How to Create a Plugin for Gothic | Beginner's Guide")

## Requirements

- [Union Primary Universal](https://drive.google.com/file/d/1HujF5KCAKlvqL5Qi8EtiT8GsG5WDpDf2/view)
- [Union 1.0m](https://drive.google.com/file/d/1AkU5qvxIx7zc3kdpGAwlgA-2WiGS7sU5/view) - if you wish to use an older version, you need [zParserExtender](https://worldofplayers.ru/threads/41999/) as well.

## Installation

All you have to do is put **gSplashDamage.vdf** inside `/Data/Plugins` directory of your Gothic installation. You can download it from the [releases](https://github.com/Kormic1/gSplashDamage/releases) subpage of this repository.

Enjoy.
